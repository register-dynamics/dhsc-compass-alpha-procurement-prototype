{# Sketch 1g: Search results. What someone sees after searching from Search and browse. Dylan's flow has three kinds of page a search can land on, so all three show up here as results: categories (the category view pages), device types (the device type page) and branded devices and systems (the branded pages). A mockup: nothing is wired, the search term is fixed and the form does not submit. ── Layout ──────────────────────────────────────────────────────────────── Results are grouped by kind, each under its own h2, rather than mixed in one list. Headings give screen reader users a way to jump between groups (Accessibility/design.md, "Define page structure"), and each kind needs different columns. Groups run down the tree: categories, then device types, then branded devices and systems. A short list of counts at the top links to each group, so nobody has to scroll past one kind to reach another. Each group is a table, as on the pages it links to (Components/table.md), with a visually hidden caption and numbers right-aligned. Every group says how it is ordered, per the team convention. The search form is the one from Search and browse (role="search" and an accessible name give the search landmark), with the term filled in and "Search again" in the label, as on current/search-results. It is not a hero here, since this is a results page. Category paths are laid out like breadcrumbs, as on the device type page, with the ">" separators hidden from screen readers. The path sits in grey under each category name rather than in its own column: a column needs a noun heading, and none fitted. A visually hidden "Parent categories:" label tells screen reader users what the path is. Two thirds wide, like the other pages in this sketch. B2B, so the tables are dense. ── Content ─────────────────────────────────────────────────────────────── The search is "spinal fixation". Categories, device types and their places in the tree are GMDN, as reproduced on the other pages. Every GMDN name containing both words is listed. "Branded devices and systems" is Jill's wording (28 September 2026). It replaces "Systems and devices", which avoided "branded" because Dylan had heard users do not think in it; worth checking in research. Supplier comes first, since Jill expects people to scan for the brand. The "Supplied as" column says which is which, as the system page does. Only results with a page in this sketch link anywhere.
